# 🏥 Módulo Web de Solicitud de Citas Médicas - Hospital Regional Eleazar Guzmán Barrón

## 📖 Descripción del Proyecto
Este proyecto es una propuesta de digitalización para optimizar el proceso de solicitud de citas médicas en el Hospital Regional Eleazar Guzmán Barrón. Actualmente, los pacientes deben realizar largas colas presenciales desde la madrugada, enfrentando tiempos de espera prolongados en el área de Admisión. 

El prototipo se enfoca en la atención de pacientes asegurados por el Seguro Integral de Salud (SIS) que acceden mediante referencias médicas. El sistema simula la interoperabilidad con los servicios de **REFCON/MINSA** y el **SIS** para validar automáticamente la identidad y la vigencia del seguro del paciente.
